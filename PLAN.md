# 10X Shop — Project Plan

## Project Overview

10X Shop is an individual front-end diploma project developed as part of the 10X College 2026 cohort.

The goal is to build a responsive single-page online shopping application using React, TypeScript, Tailwind CSS v4, and the DummyJSON API.

## Project Goals

- Build a functional online shopping application.
- Practice React components, props, hooks, and Context API.
- Use TypeScript to define application data and component types.
- Implement responsive layouts with Tailwind CSS v4.
- Work with API data.
- Test and deploy the application.

## Development Plan

### Week 1 — Foundation, Login and Catalog
- Set up the Vite, React, and TypeScript project.
- Integrate Tailwind CSS v4.
- Create the main application layout and reusable components.
- Implement routing and login functionality.
- Build the product catalog.

### Week 2 — Product Details, Cart and Checkout
- Implement product details pages.
- Create shared cart state using Context API.
- Add and remove products from the cart.
- Implement quantity management and price calculations.
- Build the checkout form and order confirmation.

### Week 3 — Quality, Documentation and Deployment
- Complete responsive layouts for mobile and desktop.
- Test the main shopping workflow.
- Check TypeScript, linting, and production build.
- Prepare project documentation.
- Deploy the application using Vercel or Netlify.
- Review the final GitHub repository.
